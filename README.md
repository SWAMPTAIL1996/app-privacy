# SWAMPTAIL Privacy Policy

Bilingual privacy policy for SWAMPTAIL apps, hosted on GitHub Pages.

- Japanese: `index.html`
- English: `en.html`
- Shared styles: `style.css`
- Static hosting marker: `.nojekyll`

Contact: support.k.k.swamptail@gmail.com

## Publish

Upload these files to the root of a dedicated public repository (for example, `app-privacy`).
In **Settings → Pages**, choose **Deploy from a branch**, **main**, **/(root)**, then **Save**.
Use the site URL shown by GitHub Pages in Google Play Console.

Only this folder contains the website. Do not upload Unity project files, keystores, or signing passwords.
